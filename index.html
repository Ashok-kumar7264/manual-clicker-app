What it does

One job, done on the device itself.

Tap points
Place a target anywhere on the screen. The app taps that spot for you.
Adjustable interval
Choose how often each tap happens.
Floating controls
Start and stop from an overlay while another app is open.
Works in other apps
Taps land on whatever app is in the foreground.
No root
Taps are sent through Android's Accessibility Service, so your phone does not need to be rooted.

How it works

Setup takes a few minutes the first time.

  1. Install the appDownload it and open it.
  2. Enable the serviceTurn on Manual Clicker in Android Accessibility settings.
  3. Set tap pointsPlace targets and choose the interval.
  4. StartPress start. Press stop at any time.

About the Accessibility permission

Android requires it for any app that taps the screen for you.

What it is used for

Manual Clicker uses the Accessibility Service to perform the taps you set up. Android shows its own prompt before you turn it on, so read that prompt on your device.

How to turn it off

Open Settings, then Accessibility, then Manual Clicker, and switch it off. Taps stop right away.

Questions

Short answers to the common ones.

Does my phone need to be rooted?

No. Manual Clicker uses the Accessibility Service, which does not require root.

Why does it ask for Accessibility access?

That is the Android feature that lets an app tap on your behalf. Without it, automatic taps are not possible.

How do I stop it?

Press stop in the floating controls, or switch the service off in Android Accessibility settings.

Can any app be used with it?

Technically yes, but some apps restrict automated input in their terms of use. Check the terms of each app you use it with.
